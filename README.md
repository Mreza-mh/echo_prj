# EchoMind 🫀

> سامانه هوشمند مدیریت و تحلیل اکوکاردیوگرافی، ارزیابی ریسک قلبی، مدیریت کلینیک، دستیار گفت‌وگویی و پایش لحظه‌ای ضربان قلب

**EchoMind** یک پلتفرم یکپارچه و هوشمند برای کلینیک‌های قلب است که با هدف ترکیب **مدیریت فرایندهای کلینیکی، تحلیل هوشمند تصاویر و ویدیوهای اکوکاردیوگرافی، ارزیابی ریسک قلبی، دستیار هوشمند و پایش لحظه‌ای علائم حیاتی** طراحی و پیاده‌سازی شده است.

این سامانه با استفاده از یک معماری **میکروسرویسی سبک** توسعه داده شده تا بخش‌های مختلف سیستم بتوانند به‌صورت مستقل توسعه، اجرا و در صورت نیاز مقیاس‌دهی شوند.

## ✨ قابلیت‌های اصلی

### 🏥 مدیریت کلینیک

* احراز هویت و مدیریت کاربران با نقش‌های مختلف
* مدیریت پزشکان و کارکنان
* مدیریت خدمات و منابع کلینیک
* نوبت‌دهی
* تقویم تعاملی و برنامه کاری
* مدیریت اطلاعات بیماران
* مشاهده سوابق و اطلاعات بالینی
* پنل‌های اختصاصی برای نقش‌های مختلف

---

### 🫀 تحلیل هوشمند اکوکاردیوگرافی

یکی از بخش‌های اصلی EchoMind، خط پردازش ویدیوی اکوکاردیوگرافی است که به‌صورت مستقل و با استفاده از Python پیاده‌سازی شده است.

این بخش شامل مراحل مختلفی از پردازش و تحلیل است:

* تشخیص و طبقه‌بندی نمای اکوکاردیوگرافی
* تشخیص رویدادهای چرخه قلب
* پردازش و تحلیل ویدیو
* اندازه‌گیری ساختارهای قلب
* قطعه‌بندی ساختارهای موردنظر
* برآورد حجم حفره‌های قلب
* استفاده از منطق فازی برای ترکیب نتایج
* استفاده از مدل‌های یادگیری ماشین برای برآورد ریسک قلبی-عروقی
* تولید خروجی و گزارش تحلیل

این خط پردازش به‌صورت مستقل از بک‌اند اصلی اجرا می‌شود و برای هر ویدیوی ورودی، فرایند تحلیل را انجام می‌دهد.

---

### 🤖 دستیار هوشمند

EchoMind دارای یک دستیار گفت‌وگویی است که برای تعامل طبیعی‌تر کاربران با سامانه طراحی شده است.

قابلیت‌های این بخش شامل:

* تشخیص نیت پیام کاربر
* جستجوی معنایی در پایگاه دانش
* پاسخ‌گویی به پرسش‌های متداول
* فرایند گفت‌وگومحور رزرو نوبت
* استفاده از Embedding برای درک معنایی متن
* استفاده از پایگاه داده برداری برای بازیابی اطلاعات مرتبط
* اتصال به مدل زبانی برای تولید پاسخ

سرویس هوش مصنوعی به‌صورت مستقل با **FastAPI** پیاده‌سازی شده و از **Qdrant** برای ذخیره و جستجوی بردارهای معنایی استفاده می‌کند. همچنین برای تولید Embedding از مدل‌های مبتنی بر Sentence-Transformer به‌صورت محلی استفاده شده است.

---

### 📊 ارزیابی ریسک قلبی

در بخش تحلیل داده‌های بالینی، از مدل‌های یادگیری ماشین برای برآورد ریسک استفاده شده است.

مدل‌های مورد استفاده شامل:

* **CatBoost**
* **Logistic Regression**

نتایج این مدل‌ها در کنار نتایج حاصل از تحلیل اکوکاردیوگرافی و سایر داده‌های بالینی مورد استفاده قرار می‌گیرند.

> این بخش با هدف پژوهشی و دانشگاهی توسعه داده شده و جایگزین تشخیص پزشک نیست.

---

### ❤️ پایش لحظه‌ای ضربان قلب

سامانه از یک ماژول سخت‌افزاری مبتنی بر **ESP32** و سنسور **MAX30102** برای پایش لحظه‌ای ضربان قلب استفاده می‌کند.

ارتباط بین سخت‌افزار و سرور از طریق پروتکل **MQTT** انجام می‌شود.

```text
سنسور MAX30102
       ↓
      ESP32
       ↓ MQTT
Mosquitto Broker
       ↓
Laravel Backend
       ↓
    MongoDB
       ↓
Angular Dashboard
```

دستگاه در طول یک جلسه فعال، داده‌های ضربان قلب را به‌صورت دوره‌ای منتشر می‌کند و این داده‌ها در سمت سرور دریافت و ذخیره شده و در پنل کاربر نمایش داده می‌شوند.

همچنین برای افزایش اطمینان سیستم، مکانیزم‌هایی مانند **محدودیت زمان جلسه، توقف خودکار در صورت قطع ارتباط MQTT و تشخیص خروج انگشت از سنسور** در نظر گرفته شده است.

# 🏗️ معماری سیستم

EchoMind از چند مؤلفه مستقل تشکیل شده است که هرکدام وظیفه مشخصی را بر عهده دارند:

```text
                       ┌─────────────────────┐
                       │   Angular Frontend  │
                       │      Angular 20     │
                       └──────────┬──────────┘
                                  │
                                  ▼
                       ┌─────────────────────┐
                       │   Laravel Backend   │
                       │ Laravel 12 / PHP 8.4│
                       └───────┬───────┬─────┘
                               │       │
                    ┌──────────┘       └──────────┐
                    ▼                             ▼
          ┌─────────────────┐           ┌─────────────────┐
          │   AI Service    │           │    Databases    │
          │ FastAPI + Qdrant│           │ MySQL / MongoDB │
          └─────────────────┘           │     / Qdrant    │
                                        └─────────────────┘


          ┌─────────────────────────────────────────┐
          │      Echocardiography Pipeline          │
          │                Python                   │
          │                                         │
          │  View Classification                    │
          │  Cardiac Cycle Detection                │
          │  Measurements & Segmentation            │
          │  Volume Estimation                      │
          │  Fuzzy Logic                            │
          │  Risk Estimation                        │
          └─────────────────────────────────────────┘


                  ┌─────────────────┐
                  │  MQTT Broker    │
                  │    Mosquitto    │
                  └────────┬────────┘
                           │
                           ▼
                  ┌─────────────────┐
                  │      ESP32      │
                  │    MAX30102     │
                  └─────────────────┘
```

مؤلفه‌های اصلی پروژه عبارت‌اند از: **Laravel Backend، سرویس FastAPI/Qdrant، خط پردازش Python، Angular Frontend و Mosquitto برای ارتباط MQTT**. در کنار این موارد، Kong Gateway نیز برای مدیریت و مانیتورینگ ترافیک API استفاده شده است.
